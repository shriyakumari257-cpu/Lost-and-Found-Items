🔎 College Campus Lost & Found

A web-based Lost & Found management system designed to help students and staff report, search, and manage lost and found items within a college campus.

📌 About the Project

Finding a lost item on a college campus can be difficult when there is no centralized system to report it.

This project provides a simple platform where users can:

- Report lost items
- Report found items
- Search for reported items
- View item details
- Connect lost items with their possible owners
- Manage lost and found records

The project was developed as a team project during a college hackathon.

✨ Features

- 📝 Report Lost Items
- 📦 Report Found Items
- 🔍 Search and Browse Items
- 📋 View Item Details
- 🤝 Helps connect owners with found items
- 🌐 User-friendly web interface
- 💾 Backend support for storing item information
